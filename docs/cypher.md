## Q03

**upsert_state**: after every navigation. Tells the explorer whether the page is new, whether it has been read, and its previous candidate list (to spot elements a release added to a known page).

Params: $key, $route, $auth, $fingerprint, $name, $url, $agent, $elements (JSON string), $entry, $now

Callers: clew/explorer/worker.py

```cypher
MERGE (s:State {key: $key})
  ON CREATE SET s.route = $route, s.auth = $auth, s.fingerprint = $fingerprint, s.name = $name,
                s.url_example = $url, s.first_seen = $now, s.first_seen_by = $agent,
                s.importance = 0.0, s.visits = 0, s.read = false, s.entry = false
WITH s, s.elements AS previous_elements
```

## Q04

**upsert_actions**: the page reader's output; marks the page as read even if it has no actions. HAS_ACTION edges cost 0, so a route's cost is its number of steps.

Params: $state, $name (nullable), $actions (list of maps: key, label, role, name, by, selector, kind, input_case, inputs, instance_policy, status, skip_reason, priority, origin), $now

Callers: clew/explorer/worker.py, clew/mcp_server/tools_strategist.py, clew/api/missions.py

```cypher
MATCH (s:State {key: $state})
SET s.read = true, s.name = coalesce($name, s.name)
WITH s
UNWIND $actions AS act
MERGE (a:Action {key: act.key})
  ON CREATE SET a.state_key = $state, a.label = act.label, a.role = act.role, a.name = act.name,
                a.by = act.by, a.selector = act.selector, a.kind = act.kind,
                a.input_case = act.input_case, a.inputs = act.inputs,
                a.instance_policy = act.instance_policy, a.next_instance = 0,
                a.status = coalesce(act.status, 'untried'), a.skip_reason = act.skip_reason,
                a.tries = 0, a.priority = act.priority, a.origin = act.origin,
                a.aliases = [], a.created_at = $now
MERGE (s)-[h:HAS_ACTION]->(a)
  ON CREATE SET h.cost = 0
RETURN count(a) AS added
```

## Q07

**record_transition**: what this action did in this release (procedural memory). Broken edges cost 1000. `via` keeps the route that led to the action's page, so a replay can reproduce the same context.

Params: $action, $target, $release, $ok, $error, $ms, $agent, $work_kind, $via (JSON: actions, states), $now

Callers: clew/explorer/worker.py


## Q11

**repro_steps**: shortest route from the logged-out entry page to any trigger of the bug (the repro steps). algo.SPpaths yields nothing when source = target, so a trigger on the entry page is its own branch. The caller takes the row with the lowest cost.

Params: $sig

Callers: clew/explorer/worker.py (confirm, verify_fix), clew/mcp_server/tools_reporter.py

```cypher
MATCH (b:Bug {sig: $sig})-[:TRIGGERED_BY]->(a:Action)<-[:HAS_ACTION]-(h:State {entry: true, auth: 'out'})
WITH a, h LIMIT 1
RETURN [a.key] AS steps, [h.key] AS states, 0.0 AS cost
UNION ALL
MATCH (b:Bug {sig: $sig})-[:TRIGGERED_BY]->(a:Action)<-[:HAS_ACTION]-(s:State)
MATCH (h:State {entry: true, auth: 'out'})
WHERE s <> h
CALL algo.SPpaths({sourceNode: h, targetNode: s, relTypes: ['HAS_ACTION', 'LEADS_TO'],
                   weightProp: 'cost', pathCount: 1})
YIELD path, pathWeight
WITH a, path, pathWeight ORDER BY pathWeight ASC LIMIT 1
RETURN [n IN nodes(path) WHERE n:Action | n.key] + [a.key] AS steps,
       [n IN nodes(path) WHERE n:State | n.key] AS states, pathWeight AS cost
```

## Q12

**upsert_bug**: one node per signature (dedup); every sighting adds a trigger and a release. A filed bug seen in a release for the first time gets needs_comment ("still present in v2").

Params: $action, $release, $sig, $kind, $title, $initial_status, $severity, $evidence (JSON string), $now

Callers: clew/explorer/worker.py, clew/scheduler/regressions.py

```cypher

MERGE (b:Bug {sig: $sig})
  ON CREATE SET b.kind = $kind, b.title = $title, b.status = $initial_status, b.first_seen = $now,
                b.count = 0, b.severity = $severity, b.release_found = $release, b.evidence = $evidence
WITH a, rel, b
OPTIONAL MATCH (b)-[seen:SEEN_IN]->(rel)
WITH a, rel, b, seen IS NULL AND b.status = 'filed' AS still_present
SET b.count = b.count + 1, b.last_seen = $now,
    b.needs_comment = CASE WHEN still_present THEN true ELSE b.needs_comment END

MERGE (b)-[:SEEN_IN]->(rel)
RETURN b.sig AS sig, b.status AS status, b.count AS count
```

## Q17

**enqueue_replays**: one replay job per working transition of the previous release, shallow first. Safe to re-run: skips actions already replayed or queued for this release. IDs: read the counter once and add the row index (SET runs eagerly, so per-row counters repeat).

Params: $previous, $release, $now

Callers: clew/scheduler/watcher.py

```cypher
MATCH (h:State {entry: true, auth: 'out'})
MATCH (s:State)-[:HAS_ACTION]->(a:Action)-[l:LEADS_TO {release: $previous}]->(:State)
WHERE l.ok = true AND NOT (a)-[:LEADS_TO {release: $release}]->()
  AND NOT (:Job {kind: 'replay', release: $release})-[:FOR]->(a)
WITH DISTINCT h, s, a
WITH a, CASE WHEN s = h THEN 0 ELSE length(shortestPath((h)-[:HAS_ACTION|LEADS_TO*]->(s))) END AS depth
WITH collect({action: a, depth: depth}) AS work
MERGE (k:Counter {name: 'job'})
  ON CREATE SET k.v = 0
WITH k, work, k.v AS base
SET k.v = base + size(work)
WITH base, work
UNWIND range(0, size(work) - 1) AS i
WITH base + i + 1 AS n, work[i].action AS a, work[i].depth AS depth
CREATE (j:Job {id: 'J-' + toString(n), kind: 'replay', status: 'queued', target: a.key,
               release: $release, priority: 50 - coalesce(depth, 40), created_at: $now})-[:FOR]->(a)
RETURN count(j) AS queued
```

## Q19

**regressions**: per-release edge diff. For every action that worked in the previous release and has no working edge in the new release to a page it reached before, `change` says how it differs: 'broken'  = it now fails (error, missing element); 'moved'   = it works but lands on a different page (route) than before; 'variant' = it lands on the same page (route) with a different layout, usually different data behind it (an empty list for another account). Variants are shown in the diff but not filed. Actions that already failed somewhere in the previous release are skipped: their outcome depended on hidden state, so a change there is not evidence of a regression (docs/decisions.md).

Params: $previous, $release

Callers: clew/scheduler/regressions.py, clew/mcp_server/tools.py (release_diff), clew/api/app.py

```cypher
MATCH (s:State)-[:HAS_ACTION]->(a:Action)-[was:LEADS_TO {release: $previous}]->(t1:State)
WITH s, a, collect(DISTINCT CASE WHEN was.ok THEN t1.key END) AS ok_before,
     collect(DISTINCT CASE WHEN was.ok THEN t1.route END) AS routes_before,
     collect(DISTINCT CASE WHEN was.ok THEN t1.name END) AS names_before,
     sum(CASE WHEN was.ok THEN 0 ELSE 1 END) AS failed_before
WHERE failed_before = 0 AND size(ok_before) > 0
MATCH (a)-[now:LEADS_TO {release: $release}]->(t2:State)
WITH s, a, ok_before, routes_before, names_before,
     collect({key: t2.key, route: t2.route, name: t2.name, ok: now.ok, error: now.error}) AS after
WHERE none(x IN after WHERE x.ok AND x.key IN ok_before)
WITH s, a, ok_before, names_before, after,
     CASE WHEN any(x IN after WHERE NOT x.ok) THEN 'broken'
          WHEN any(x IN after WHERE x.route IN routes_before) THEN 'variant'
          ELSE 'moved' END AS change
RETURN a.key AS action, s.name AS page, a.label AS label, change, names_before[0] AS was_target,
       ok_before[0] AS was_target_key, after[0].name AS now_target, after[0].key AS now_target_key,
       after[0].ok AS ok, after[0].error AS error
```

## Q54

**release_changes**: what a release changed besides regressions: renames healed, bugs fixed, bugs still present, pages first seen after the deploy.

```cypher

OPTIONAL MATCH (fb:Bug)-[:FIXED_IN]->(rel)
```
